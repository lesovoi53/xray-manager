# X-Manager

Серверный установщик и терминальный диспетчер сетевых служб для **Debian 12–13, x86_64 (amd64), systemd**. Объединяет управление Snell, Mieru, OpenFlux, WebDAV Tunnel, DNS-туннелями, установленными WDTT/CSQTT и локальным сервером подписок TUNA.

Документация соответствует выпуску **v2026.09.26.4**. Возможности сверены с кодом этого репозитория и первоисточниками компонентов. X-Manager настраивает и связывает отдельные программы; протоколы, шифрование и транспортные движки принадлежат их авторам.

## Что умеет

| Область | Возможности |
|---|---|
| Установка | Проверка платформы, подбор свободных разрешённых портов, установка выбранных компонентов, конфигурации и службы systemd |
| Обновление | Полный выпуск из собственного GitHub Release, закреплённые версии компонентов и SHA-256, сохранение существующих настроек |
| Восстановление | Резервирование управляемых файлов, SQLite, правил iptables и состояний служб; автоматический откат при ошибке установки и ручное восстановление |
| Xray | Обнаружение совместимых локальных шлюзов standalone Xray или интеграция с поддерживаемой базой панели; маршрутизация через Xray либо Direct |
| Snell / Mieru | Порты, реквизиты, имена, настройки протокола, ссылки и QR-коды, маршрутизация, доступ, логи и перезапуск |
| OpenFlux | Восемь экземпляров, классический и Multi-Stream режимы, транспорт, кодек, ключ, диагностика облачных ссылок, каталог и bundle v2 для TUNA |
| WebDAV | Selfhosted, Яндекс, Mail.ru, произвольный WebDAV и пул; отдельные учётные записи, шифрование, маршрутизация, PROPFIND-тест, каталог подключений |
| WDTT / CSQTT | Управление уже установленными службами, ссылки, доступ и диагностика; WDTT — Xray/Direct, CSQTT — управление доступом к веб-интерфейсу |
| DNS-туннели | Установка и переключение CottenDNS / MasterDnsVPN, домен, ключ, маршрут, WAN-доступ и три профиля stormdns:// |
| Подписки TUNA | Пользователи, несколько ссылок на протокол, персональные токены, ревизии, каталоги OpenFlux/WebDAV, обычная Base64-выдача и JSON групп |
| Группы клиента | Профили, URL_TEST/SPEEDTEST, BEST/PRIORITY, состав и порядок, параметры измерений, защита от конфликта ревизий |
| Системные инструменты | Фаервол, поиск и проверка сертификатов, DNS системы, BBR, swap и Fail2ban |

## Практические преимущества сборки

1. **Один интерфейс для нескольких независимых служб.** Общая навигация, диагностика, ссылки и управление подписками уменьшают число отдельных конфигурационных операций.
2. **Согласованный выпуск.** Установщик получает проверенные по SHA-256 бинарники из своего Release, а не произвольные upstream latest во время установки. Сборка Go на VPS не нужна.
3. **Обновление с сохранением состояния.** Установщик резервирует управляемые данные и сохраняет реквизиты и ранее остановленные службы; имеется путь восстановления после частичной ошибки.
4. **Связь с существующим Xray.** Поддерживаемая панель необязательна: можно использовать совместимые шлюзы standalone Xray и нестандартные порты.
5. **Единая выдача TUNA.** Каталоги компонентов и пользовательские группы объединены в серверной части, с сохранением прежнего формата подписки.

Это преимущества интеграции и обслуживания. Сравнительные измерения, доказывающие более высокую скорость, меньшую задержку или более сильное шифрование относительно оригинальных программ, не проводились. Подробности и границы сравнения — в [отдельном документе](docs/UPSTREAM_COMPARISON.md).

## Установка и запуск

Нужны root, Debian 12/13 amd64, работающий systemd, доступ к APT Debian и GitHub Releases. Для режима Xray сначала должны быть подготовлены совместимые локальные шлюзы; для самостоятельной установки без Xray предусмотрен `--direct`.

Проверяемая загрузка полного выпуска и команды всех режимов приведены в [руководстве](docs/USER_GUIDE.md#установка). После установки:

```bash
x-manager
```

Главное меню:

```text
[1] Пользователи и подписки TUNA
[2] Службы и туннели
[3] Xray и маршрутизация
[4] Сеть и безопасность
[5] Диагностика и состояние служб
[6] Обновление и восстановление
[7] Справка
[0] Выход
```

Быстрые команды: `x-sub`, `x-snell`, `x-mieru`, `x-openflux`, `x-webdav`, `x-wdtt`, `x-csqtt`, `x-dns`, `x-ssl`, `x-fw`, `x-opt`.

## Условия эксплуатации

- Сервер подписок в согласованной схеме слушает **только 127.0.0.1:22217**. Подписку забирает другой локальный сервис; этот адрес не предназначен для прямого подключения телефона.
- Новые управляемые порты выбираются среди свободных, **443 и 8443 исключаются**. Существующие значения не переназначаются молча. Числа 10808, 12345 и 12346 — предпочтительные значения, а не обязательные порты.
- Xray, WDTT и CSQTT не устанавливаются и не заменяются этим выпуском. Компоненты сборки берутся из собственного Release; системные пакеты — из APT Debian.
- Совместимость клиента зависит от поддерживаемых им схем URI и версии. Группы `connection-groups-v1` требуют соответствующей реализации TUNA; наличие Base64-подписки само по себе не делает все протоколы совместимыми с любым приложением.
- Токены и URI являются секретами. В SQLite хранятся и открытые токены, и их хеши: локальное управление позволяет повторно показать ссылку. Это не хранилище с шифрованием секретов на диске.
- Проверены 85 автоматических тестов и сценарии Debian 12/13; результаты развёртывания зафиксированы отдельно. Измерения на телефоне и сквозной трафик всех транспортов не входят в эти доказательства.
- Исправление ручного переключения Mieru/DNS на сохранённый порт и его проверки описаны в [отчёте v2026.09.26.1](docs/MANUAL_ROUTING_FIX_20260926.md). Общие ограничения приёмки сохраняются.
