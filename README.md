> Автоматическая интеграция **Snell v5 (0-RTT)**, **Mieru (mita Anti-TSPU)**, **WDTT (qwdtt)**, **CSQTT**, **DNS-туннелей (CottenDNS / MasterDnsVPN)** и **Сервера подписок TUNA** с ядром **Xray (3X-UI)**. Включает центр управления файрволом портов, мастер SSL/ACME сертификатов и комплексную оптимизацию ОС (системный DNS с замером пинга, адаптивный TCP BBR под RAM, SWAP 2/4 ГБ и защита Fail2ban).

---

## 🎯 О проекте

**X-Manager** превращает чистый VPS (или сервер с уже установленной панелью **3X-UI** и **qwdtt**) в защищённый, высокопроизводительный сетевой шлюз. Проект написан на чистом Bash и стандартной библиотеке Python 3 без сторонних фреймворков и веб-надстроек.

Скрипт берёт на себя всю рутину системного администратора:
* Устанавливает и настраивает все передовые протоколы обхода блокировок.
* Интегрирует их с маршрутизацией ядра Xray через локальные шлюзы (`Mixed Gateway`, `TPROXY Gateway`, `REDIRECT Gateway`), которые **штатно отображаются и управляются в веб-панели 3X-UI**.
* Обеспечивает полный перехват трафика **TCP + UDP** для Snell v5 и гибридный `mixed` протокол с UDP для Mieru.
* Включает встроенный высокоскоростной **сервер подписок TUNA** с раздачей Base64-ссылок и защитой токенами.
* Тонко оптимизирует ядро Linux под аппаратные характеристики сервера.
* Защищает сервер встроенным файрволом портов и сервисом **Fail2ban** с автоопределением кастомных портов SSH.
* Предоставляет интерактивный терминальный интерфейс с быстрыми алиасами для каждого компонента (`x-snell`, `x-mieru`, `x-wdtt`, `x-sub`, `x-ssl`, `x-fw`, `x-opt`).

## 🧩 Возможности и экосистема

### 1. ⚡ Snell v5.0.1 (Гибридный режим 0-RTT, TCP + UDP перехват)
* **Двойной режим работы:**
  * На **Android / Windows** (**NekoBox+**, **sing-box**) работает на максимальной скорости по чистому TCP с поддержкой мультиплексирования соединений (**Connection Reuse**) и **TCP Fast Open (TFO)**.
  * На устройствах **Apple** (**Surge**, **Shadowrocket**, **Loon**) автоматически задействует быстрый протокол **QUIC 0-RTT** поверх UDP.
* **Полный перехват в ядро (TCP + UDP):** исходящий трафик Snell заворачивается в шлюз Xray `REDIRECT Gateway` (:12346) как для TCP, так и для UDP, а ответы клиентам на собственный порт (QUIC) защищены от зацикливания.
* **Маскировка:** встроенный HTTP-обфускатор (`kinopoisk.ru` и др.) для обхода глубокого анализа пакетов (DPI).
* **Готовые ссылки:** автоматическая генерация ссылок `snell://` с уже включенными параметрами `&reuse=true&tfo=true`, QR-кодов и строк конфигурации Surge.

### 2. 🚀 Mieru (mita v3.37+) с защитой от ТСПУ
* Протокол с маскировкой под случайный шум, устойчивый к активному зондированию цензоров.
* **Режимы низкой энтропии (Low-Entropy):** пресеты `LOW_ENTROPY_MODE_32`, `40`, `48`, `56`.
* **Вращение маски (Mask Rotation):** `LOW_ENTROPY_MASK_ROTATE_RIGHT_7` и конструктор пользовательских параметров.
* **Интеграция с Xray:** egress направляется на `Mixed Gateway` (:10808) с протоколом `mixed`, включенным UDP и поддержкой редактирования в 3X-UI.
* **Интерактивный конструктор профилей** в меню Mieru с автогенерацией ссылок `mierus://` и QR-кодов.

### 3. 🛡️ WDTT / qwdtt (WireGuard over WebSocket / TURN)
* Высокоскоростной туннель для стабильного транспорта в условиях жёстких сетевых ограничений.
* **Два режима выхода:** прозрачный перехват через **Xray Balancer (TPROXY Gateway :12345)** или **Прямой выход (Direct WAN)** с NAT Masquerade.
* Мониторинг в реальном времени: счётчики байт (Rx/Tx), статус воркеров ядра, число активных клиентов.

### 4. 📋 Сервер подписок TUNA (`tuna-subscriptions`)
* Автономный высокопроизводительный демон на стандартной библиотеке Python 3 (zero external dependencies).
* **База данных SQLite в режиме WAL:** высокая скорость и безопасность при параллельных запросах клиентов.
* **Криптографическая безопасность:** Bearer-токены хранятся в виде SHA-256 хешей, поддержка быстрой ротации токенов.
* **Точное сохранение URI:** ссылки на протоколы (`mierus://`, `snell://`, `qwdtt://`, `stormdns://`, `vless://`) сохраняются в неизменном виде без повреждения параметров.
* **Поддержка HTTP-кэширования (ETag / 304 Not Modified):** минимизирует трафик и нагрузку на сервер при регулярном обновлении клиентов.
* **Выдача подписок:** по прямому запросу `/sub/<token>` сервер отдаёт Base64-список конфигураций, совместимый с любыми клиентами (NekoBox, Happ, v2rayN, sing-box, Streisand, FoXray).

### 5. 🔒 CSQTT (VPN Server & Изоляция веб-панели)
* Высокопроизводительный UDP-туннель на базе современного криптографического протокола VK Video Relay.
* **Изоляция панели администрирования (SSH-Tunnel Only):** порт веб-панели закрывается от сканеров и ботов из внешней сети (`DROP ! -i lo`).
* Готовая строка для безопасного входа через зашифрованный SSH-туннель:
  ```bash
  ssh -N -L 37002:127.0.0.1:37002 root@IP_СЕРВЕРА -p SSH_ПОРТ
  ```

### 6. 🌐 DNS-Туннели (CottenDNS / MasterDnsVPN)
* Туннелирование трафика через DNS-запросы (порт `:53 UDP/TCP`) для обхода тотальных белых списков.
* **CottenDNS (WhiteDNS Engine) и MasterDnsVPN:** переключение в 1 клик без конфликта портов.
* **3 профиля `stormdns://`:** «Жёсткая цензура» (x4 дублирование), «Стандартный» (x2) и «Мобильный / Скоростной» (x1).

### 7. 🛡️ Центр управления файрволом портов (`x-fw`)
* **Включение и выключение протоколов без остановки служб:** моментальное закрытие или открытие входящего порта любого протокола (Mieru, Snell, WDTT, CSQTT, DNS, 3X-UI) через правила iptables.
* **Режим экстренного локдауна (Emergency Lockdown):** мгновенная блокировка всех прокси-портов с сохранением доступа по SSH.
* **Синхронизация портов:** автоматическое открытие актуальных портов и очистка устаревших правил при смене портов или перезапуске.

### 8. 🔒 Управление SSL-сертификатами (`x-ssl`)
* Выпуск и продление бесплатных SSL-сертификатов Let's Encrypt через `acme.sh`:
  * **Cloudflare DNS-01:** выпуск Wildcard-сертификатов (`*.domain.com`).
  * **HTTP-01 Standalone:** автоматический выпуск по порту `:80`.
* **Мультипутевой детектор:** автоматический поиск и привязка существующих сертификатов из `/root/cert/`, `/etc/x-ui/`, `/etc/letsencrypt/`, `/etc/ssl/`.
* Привязка сертификатов к веб-панели 3X-UI и туннелям.

### 9. ⚙️ Системная оптимизация и безопасность (`x-opt`)
* **🌐 Смена системного DNS с замером пинга в реальном времени:**
  * 16 провайдеров (Yandex, Cloudflare, Google, Quad9, Control D, AdGuard, OpenDNS и др.) с параллельным замером задержки в мс.
  * Фиксация в `/etc/resolv.conf`, `systemd-resolved` и `dhclient.conf`.
* **🚀 Включение BBR и адаптивный тюнинг буферов под RAM:**
  * Автоматический расчёт сетевых буферов под точный объём оперативной памяти (до 1.5 ГБ, 2–4 ГБ, > 4 ГБ).
  * Включение `tcp_fastopen = 3`, `tcp_tw_reuse = 1`, `tcp_fin_timeout = 20`, `tcp_slow_start_after_idle = 0`.
* **💾 Управление файлом подкачки SWAP:**
  * Создание/удаление swap-файла на **2 ГБ** или **4 ГБ** с тюнингом `vm.swappiness = 10` и `vm.vfs_cache_pressure = 50`.
* **🛡️ Защита Fail2ban:**
  * Автоопределение нестандартного SSH-порта и изолированный jail.
  * Просмотр банов, ручной бан/разбан, настройка времени бана.

* **Операционная система:** Debian 11 / 12 / 13, Ubuntu 20.04 / 22.04 / 24.04

## 🕹️ Быстрые команды управления

После установки диспетчер доступен через удобные системные команды из любой точки терминала:

| Команда | Назначение |
| :--- | :--- |
| **`x-manager`** | **Главный центр управления** всеми протоколами, сводный статус, порты и шлюзы |
| **`x-sub`** / **`x-tuna`** | **Сервер подписок TUNA:** профили пользователей, выдача Base64-ссылок, ротация токенов |
| **`x-ssl`** / **`x-cert`** | **Управление SSL:** Cloudflare Wildcard DNS-01, HTTP-01 Standalone, автодетекция |
| **`x-opt`** / **`x-sys`** | **Центр системной оптимизации:** DNS с пингом, TCP BBR, SWAP 2/4G, Fail2ban |
| **`x-fw`** / **`x-firewall`** | **Центр управления файрволом портов:** отключение протоколов, локдаун |
| **`x-snell`** | Управление **Snell v5** (роутинг Xray/Direct TCP+UDP, PSK, порты, HTTP-обфускация, QR) |
| **`x-mieru`** | Управление **Mieru** (Anti-TSPU пресеты, Low-Entropy, пользователи, порты, QR) |
| **`x-wdtt`** / **`x-qwdtt`** | Управление **WDTT** (маршрутизация TPROXY/Direct, клиенты, смена пароля) |
| **`x-csqtt`** | Управление **CSQTT** (изоляция веб-панели, SSH-туннель, фаервол) |
| **`x-dns`** | Управление **DNS-туннелями** (CottenDNS / MasterDnsVPN, ссылки `stormdns://`, WAN) |

## 📱 Клиентские приложения и импорт

### 1. NekoBox+ (Android / Windows)
* **Подписки TUNA:** перейдите в `Группы` ➔ `Добавить группу` ➔ вставьте ссылку формата `http://IP:22217/sub/ВАШ_ТОКЕН` ➔ все протоколы обновятся автоматически.
* **Mieru:** импорт через `mierus://` или QR-код из меню `x-mieru`.
* **Snell v5:** ссылка генерируется с параметрами `&reuse=true&tfo=true` для максимальной производительности.

### 2. Surge / Shadowrocket / Loon (iOS / macOS)
* В меню `x-snell` генерируется готовая строка для Surge:
  ```ini
  Snell-v5 = snell, IP_СЕРВЕРА, ПОРТ, psk=ВАШ_PSK, version=5, reuse=true, tfo=true, udp-relay=true
  ```
* Поддержка **QUIC 0-RTT** поверх UDP на устройствах Apple.

### 3. Karing / sing-box / Happ / v2rayN
* Прямая поддержка ссылок из подписок TUNA и нативных протоколов.

## 🔒 Безопасность и архитектура портов

```
[Интернет / Входящие подключения клиентов]
        │
        ├── :1488 (Snell v5)       ──► [Snell Server] ──(TCP+UDP)──┐
        ├── :2020-2030 (Mieru)     ──► [mita core]    ──(SOCKS5)───┤
        ├── :56000 (WDTT UDP)      ──► [wdtt-tproxy]  ──(TPROXY)───┼──► [3X-UI / Xray Core]
        ├── :53 (CottenDNS/Master) ──► [DNS Tunnel]   ──(SOCKS5)───┤     │
        ├── :22217 (TUNA Sub API)  ──► [tuna-sub-server] (127.0.0.1)│     • Mixed Gateway    :10808 (127.0.0.1 🔒)
        └── :SSH (SSH + Fail2ban)  ──► [sshd]                      │     • TPROXY Gateway   :12345 (127.0.0.1 🔒)
                                                                   │     • REDIRECT Gateway :12346 (127.0.0.1 🔒)
[Изолированная веб-панель CSQTT]                                   │
  :37002 (TCP) ──► Доступна ТОЛЬКО через SSH-туннель ──────────────┘
```

* **Шлюзы Xray в панели 3X-UI** (`Mixed Gateway` :10808, `TPROXY Gateway` :12345, `REDIRECT Gateway` :12346) изолированы на `127.0.0.1` (`DROP ! -i lo`) и исключены из шаблона во избежание дублирования сокетов.
* **Сервер подписок TUNA** слушает только локальный интерфейс (`127.0.0.1:22217`) или подключается через внешний reverse proxy / прямой порт с авторизацией по токенам.
* **Защита Fail2ban** блокирует атаки перебора паролей на реальном SSH-порту.
