# X-Manager v2026.10.07.2

## Исправления

- Устранён HTTP 500 при выдаче подписки после выбора Snell v6: пользователь
  `tuna-sub` теперь может проверять наличие отметок остановки и отключения.
  Каталоги управления получают `0711`; содержимое закрытых файлов остаётся
  недоступным, права записи другим пользователям не предоставляются.
- При обновлении существующие каталоги исправляются через `service-control.py
  reconcile`, который уже вызывается установщиком. Отметки stop/off сохраняются.
  Повторные действия управления службами не возвращают прежние права `0700`.
- В выборе версии Snell и в списке служб отображается фактическое состояние v6.
  Отсутствующая конфигурация, остановка, ошибка и запуск различаются.

## Проверка и границы

Исправления прав и обоих экранов проверены на сервере 89 без перезапуска служб;
после исправления обычная подписка и контейнер групп возвращали HTTP 200,
публичная подписка содержала активный Snell v6. Для обновления добавлена
регрессия с настоящим непривилегированным процессом: проверка отметок разрешена,
чтение закрытого состояния запрещено. В изолированной Debian 12 прошли
298 основных тестов и 98 тестов подписок; на прежнем коде новая регрессия
воспроизвела отказ доступа. Локальные тесты не заменяют проверку
полной установки этого выпуска на VPS.

Версии и контрольные суммы всех компонентов сохранены от v2026.10.07.1.
Ключи, UUID, ссылки, порты и настройки протоколов не мигрируются.
Этот выпуск не меняет обработку дублей и кэш внешних подписок панели.

## Обновление и откат

В X-Manager выберите «Обновление и восстановление → Обновить полный выпуск».
Установщик создаёт резервную копию перед заменой файлов. Для отката используйте
«Восстановить резервную копию» и выберите копию, созданную перед обновлением.
После обновления заново откройте `x-manager`, чтобы загрузить новое меню.
