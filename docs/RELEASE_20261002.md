# X-Manager v2026.10.02.1

Полный выпуск для Debian 12–13 amd64. Включает изменения установщика, меню,
серверных помощников и документации. Десять архивов/бинарников компонентов
сохранены с прежними SHA-256; обновления upstream автоматически не подхватываются.

## Исправления

- Волга: первый отказ SmartCaptcha больше не создаёт тупик «нет каналов».
  Ссылки сохраняются в закрытом черновике; после получения cookies настройка
  продолжается через меню. Рабочий канал заменяется только после проверки.
- Cookies → [6]: одна команда PowerShell скачивает помощник в профиль пользователя,
  проверяет скачивание, создаёт SSH/SOCKS-туннель и отдельное окно Chrome.
  Добавлены проверки SOCKS5/HTTPS, готовности браузера и повтор передачи cookies.
  SmartCaptcha по-прежнему проходит человек.
- Сохранены ранее внедрённые исправления Snell: UDP через TPROXY с проверкой
  совместимости Xray, собственными правилами и откатом; TCP остаётся REDIRECT.
- Mieru: оба экспорта используют состояние Mita RPC и штатный codec; добавлены
  адресные preview/repair/restore. Массовой пересборки подписок при обновлении нет.
- Существующие флаги Snell, включая индивидуальный `tfo=false`, не сбрасываются.
  Общие значения по умолчанию и протоколы не менялись.

## Установка, обновление и откат

Для новой установки используйте команду быстрого старта в [README](../README.md).
Для существующей установки: **Обслуживание → [1] Обновить полный выпуск**.
Этот пункт получает последний обычный GitHub Release, проверяет SHA-256 архива
и вызывает установщик с `--update`. Один push в main без Release его не обновляет.

Установщик проверяет ОС, архитектуру и зависимости, делает резервную копию,
сохраняет конфигурации и данные. При ошибке установки запускается восстановление.
Не закрывайте терминал до результата. После успеха заново запустите `x-manager`.

Для ручного отката используйте **Обслуживание → [2] Восстановить резервную копию**
или точную команду `Rollback:`, напечатанную установщиком. Копия может содержать
секреты: не публикуйте её. Перед поздним откатом учитывайте последующие изменения
данных и конфигураций; возврат старого снимка способен вернуть и старые ошибки.

## Проверки и ограничения

Результаты проверки именно архива этого выпуска приведены в заметках GitHub Release.
Предыдущие проверки компонентов и маршрутизации описаны в
[отчёте Snell/Mieru](SNELL_MIERU_ACCEPTANCE_20261001.md), а проверки черновиков,
Windows-помощника и ручного получения cookies — в [инструкции Волги](VOLGA_FIRST_SETUP.md).

Лабораторные проверки не означают установку полного выпуска на рабочий VPS.
Публикация сама по себе не меняет серверы. Капча зависит от Яндекса и требует
участия пользователя; автоматическое решение капчи и гарантированный срок
действия cookies не заявляются. При явном импорте cookies неудача последующей
проверки не означает автоматического возврата прежнего файла: он сохранён в копии.
