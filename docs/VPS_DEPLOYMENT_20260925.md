Активны Snell, Mieru, WebDAV, tuna-subscriptions, OpenFlux 1–2 и x-ui. У проверенных служб пакета `NRestarts=0`. OpenFlux 3 был остановлен до обновления и остался остановленным. Пользователь подписки сохранён; секреты в отчёт не включены.

Локальные проверки: API HTTP 200, прежняя Base64-подписка доступна, структурированная подписка имеет schema `tuna.subscription`, WebDAV PROPFIND вернул HTTP 207 с существующими реквизитами. Android-клиент не менялся.

## Файлы и восстановление

- Меню: `/usr/local/bin/x-manager`.
- Постоянный полный дистрибутив: `/usr/local/share/x-manager/distribution`.
- Независимая серверная копия: `/root/x-manager-install`.
- Новый архив: `/root/x-manager-clean.tar.gz`, SHA-256 проверен.
- Последняя копия перед v2: `/var/backups/x-manager-EL7pi8Jy`.
- Копия перед первым обновлением меню: `/var/backups/x-manager-BzLKGEAD`.
- Прежние серверные исходники и архив: `/var/backups/x-manager-source-I2KKgYZt`.

Ручной откат:

```bash
bash /root/x-manager-install/install.sh --rollback /var/backups/x-manager-EL7pi8Jy
```

Эта копия возвращает предыдущее состояние v1, а не удалённую ранее старую установку. Резервные копии доступны только root. Пакеты APT и системные пользователи при откате не удаляются.
