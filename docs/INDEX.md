## Приоритет документов

Текущие руководства `USER_GUIDE`, `OPERATIONS`, `DEVELOPMENT`, `ENGINEERING`
описывают выпуск 11 октября. Файлы `RELEASE_*`, `*ACCEPTANCE_*`, планы и
дневники с датами — свидетельства конкретного этапа. Они не должны переопределять
позднее принятое поведение. При расхождении проверьте код указанного выпуска
и обновите руководство; не возвращайте старую функцию по старому плану.

Клиент, сторонняя панель и облачные API имеют свои версии и ограничения.
Успешная установка не является доказательством работы каждого маршрута на
любом клиенте. Документация не содержит действующих паролей, URI, cookies,
токенов или копий баз; их место в закрытом серверном бэкапе.
