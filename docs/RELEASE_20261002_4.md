# OpenFlux: дополнительные серверы; Mieru: имя профиля

Полный выпуск X-Manager v2026.10.02.4 для Debian 12/13 amd64.

- OpenFlux: импорт с другого сервера добавляет самостоятельный бандл в подписку. Имя, UUID, группы, ключи и статус исходного подключения сохраняются. Пункт [10] позволяет включать, отключать, показывать ссылку и удалять только добавленное подключение. Повторный идентичный импорт — без дубликатов; конфликтующие настройки того же источника отклоняются.
- Mieru: генератор подписки использует имя из настройки, а не Mieru-Home. Адресное переименование существующей ссылки проверяет пользователя, ревизию, отпечаток URI, реквизиты, порты и traffic pattern; изменяет только profile. Массового переименования ручных и внешних ссылок при обновлении нет.
- Бинарники компонентов, протоколы и форматы URI сохранены. Новая таблица OpenFlux создаётся аддитивно.

Проверки: 87 тестов подписок, 7 тестов меню и 10 тестов Mieru. На сервере 89 проверены миграция и импорт на изолированной копии существующей БД, сохранность прежних данных/подписок после обновления, затем фактическая выдача исправленного имени Mieru. Не заявляется проверка VPN-подключения клиента.

Обновление: Обслуживание → [1] Обновить полный выпуск. Перед заменой установщик создаёт резервную копию. Откат — через пункт восстановления или команду из отчёта установщика. При откате только программных файлов старая версия не публикует новые дополнительные OpenFlux-записи; они остаются в БД. Не восстанавливайте старую БД поверх более поздних пользовательских изменений.
