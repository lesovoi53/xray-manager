# Приёмка выбора Snell v5 / Snell v6 — 7 октября 2026

## Принятое поведение

- Только один локальный Snell: v5 либо выбранный сохранённый endpoint v6.
- Общий ключ, без управления пользователями Snell. Три одновременных клиента проверены.
- Подписка выдаёт активную локальную версию: v4 для сервера v5, v6 для сервера v6.
- Неактивные настройки и ссылки сохраняются; внешние подключения не заменяются.
- QUIC Proxy исключён, обычный UDP relay сохраняется.

## Ограничения

Этот прогон — проверка изменения Snell и целевого обновления его файлов.
Полную чистую установку всего пакета после этой последней правки повторно
не выполняли. Предыдущие результаты полного установщика не подменяют её.
Android-проверка текущего изменения, длительная нагрузка и восстановление
после отключения питания не проведены. TLS obfs не поддерживается native v5:
при такой конфигурации проверен отказ переключения с откатом.
Непривязанные ссылки не считаются локальными автоматически.

Аудит HYDRA на прежнем сервере остановлен из-за несовпадения SSH-отпечатка;
пароль ему не передавался. Это не блокировало независимые проверки выше.
Другие VPS не изменялись. Публикации GitHub не было.

Порядок ручной приёмки: открыть Snell v6 в меню, выбрать сохранённое подключение,
активировать, обновить подписку клиента и проверить подключение. Затем через
меню явно вернуть Snell v5 и повторить проверку. Значения ключей и портов
при этом не должны меняться. Публикация — только после подтверждения.
