# Закреплённые выпуски и меню

Полный справочник по функциям, установке и ограничениям текущего выпуска: [USER_GUIDE.md](USER_GUIDE.md). Отличия от оригинальных компонентов: [UPSTREAM_COMPARISON.md](UPSTREAM_COMPARISON.md).

Поддерживаемая платформа: **Debian 12 или 13, x86_64 (amd64), systemd**.
Другие системы и архитектуры отклоняются до изменения установки.

## Источник компонентов

Рабочие загрузки выполняются только из Releases `lesovoi53/xray-manager`.
`components.json` закрепляет выпуск, версии и SHA-256 Snell, Mieru,
OpenFlux, WebDAV, CottenDNS и MasterDnsVPN. Сначала выбранные компоненты
скачиваются во временный каталог и проверяются; затем создаётся резервная
копия и заменяются рабочие файлы. Ошибка загрузки/контрольной суммы останавливает
операцию. Нет автоматического отката к upstream, ветке main или другой версии.

Системные пакеты (`python3`, `curl`, `iptables` и другие) устанавливаются через
APT Debian. Xray, WDTT и CSQTT, установленные пользователем отдельно, не
скачиваются и не заменяются этим выпуском. Компилятор Go для установки не нужен.
Скрипт `build-openflux.sh` оставлен в исходниках для подготовки будущих выпусков
разработчиком; установщик и меню его не вызывают.

## Установка и обновление

Загрузите `x-manager.tar.gz` и `SHA256SUMS` из одного выпуска:

```bash
tag=v2026.09.26.2
base="https://github.com/lesovoi53/xray-manager/releases/download/$tag"
mkdir -p x-manager-install && cd x-manager-install
curl -fLO "$base/x-manager.tar.gz"
curl -fLO "$base/SHA256SUMS"
grep '  x-manager.tar.gz$' SHA256SUMS | sha256sum -c -
tar -xzf x-manager.tar.gz
sudo bash install.sh --quick
```

Для установки без Xray выберите явно `--direct`. Для существующей установки:

```bash
sudo bash install.sh --update
```

Установленный полный дистрибутив сохраняется в
`/usr/local/share/x-manager/distribution`: из него также можно повторно запустить
установку или выполнить ручной откат. Временные каталоги обновлятора для этого
не требуются.

Из установленного меню: **Обновление и восстановление → Обновить полный выпуск**.
Обновление определяет последний выпуск собственного репозитория один раз,
загружает целый архив и SHA256SUMS из этого тега и запускает проверенный установщик.
После успеха меню выполняется заново из установленного файла. При выходе меню
не обновляется автоматически и службы не останавливаются.

## Xray без привязки к панели

Поддерживается обнаружение IPv4 loopback-шлюзов в JSON/JSONC standalone Xray,
каталогах `/etc/xray`, `/usr/local/etc/xray` и конфигурации работающего процесса.
Для нестандартного пути:

```bash
sudo XM_XRAY_CONFIG=/path/to/config.json bash install.sh
```

При нескольких подходящих входах задайте `XRAY_SOCKS_PORT`,
`XRAY_REDIRECT_PORT`, `XRAY_TPROXY_PORT` явно. Сохранённые значения не меняются
молча. SOCKS5 должен принимать no-auth на 127.0.0.1; REDIRECT и TPROXY должны
быть совместимыми dokodemo-door с followRedirect. TPROXY требует tcp,udp.
Конфигурация standalone ядра не перезаписывается. База поддерживаемой панели —
дополнительный способ обнаружения, а не обязательная зависимость.
Пункты SSL, специфичные для 3X-UI, показываются только при наличии её базы.

## Меню и группы

Главная содержит семь разделов. Основные меню служб разделены на подключения,
настройки, диагностику и обслуживание; исходные обработчики действий сохранены.
Первичные экраны не показывают реквизиты. Открытие подписок не заменяет сервис
и не запускает скрытый импорт каталогов.

Группы URL-test / Speedtest: пользователь → редактирование → группы автовыбора.
Семейство, метод, стратегия, флаги и числовые пресеты выбираются по номерам.
Участники выбираются из профилей; можно импортировать существующие ссылки
этого пользователя или добавить свои. ID и URI сохраняются. Пустой URL
Speedtest запрашивается повторно. Несохранённый завершённый черновик остаётся
в памяти редактора; при конфликте ревизий он не перезаписывает новые данные.
Выход с черновиком требует явного отказа от изменений. Черновик не переживает
закрытие процесса/SSH-сессии. Измерения выполняет клиент после подключения.

## Откат

Путь резервной копии выводится при установке. В ней есть секреты, права — 0700.
Автоматический откат выполняется при ошибке после начала транзакции.
Ручной откат: меню восстановления или команда из полного дистрибутива:

```bash
sudo bash install.sh --rollback /var/backups/x-manager-XXXXXXXX
```

Откат возвращает сохранённые конфигурации, данные SQLite, бинарники, unit-файлы,
состояния служб и iptables. Системные пакеты и созданные системные пользователи
не удаляются. Откат к более старой копии заменяет более новые данные.

## Приёмка

В изолированных Debian 12 и 13 amd64 с настоящим systemd прошли чистая
установка, повторный запуск, проверки API HTTP 200 и WebDAV PROPFIND 207,
multi-режим от wdavtunnel и сохранение остановленной/disabled службы.
Отдельно на Debian 13 проверены обновление с сохранением данных, отказ APT,
загрузки, ошибочная конфигурация и отказ настоящей службы Mieru с откатом.
Контрольная сумма повреждённого файла проверяется отдельным тестом.
Standalone Xray 26.9.9: JSON-конфигурация, обнаружение трёх нестандартных
шлюзов, SOCKS5 HTTP round-trip; исходный файл не изменён.

Это не полный тест клиентского VPN-трафика. Импорт в Android rc11,
поведение групп на телефоне, UDP/TPROXY end-to-end и внешние облачные аккаунты
проверяются отдельно. Внешний API облака может измениться даже при закреплённом
бинарнике: стабильный выпуск устраняет дрейф загрузок, но не фиксирует чужой API.
