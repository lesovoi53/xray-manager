# X-Manager v2026.10.08.4

Чистая установка теперь автоматически настраивает сетевой профиль по доступной
RAM: BBR/fq, буферы TCP, conntrack, очереди и тайм-ауты. Учитываются ограничения
cgroup, swap исключён; большие существующие лимиты сохраняются. Проверки ядра
и конфликтов выполняются до применения, исходные файлы и runtime sysctl
сохраняются для отката. Обновление существующей установки не заменяет её профиль.

Старое меню BBR использует тот же механизм. В «Обслуживание» добавлена ежедневная
перезагрузка VPS: по умолчанию выключена, время выбирается явно. Во время установки
событие пропускается без последующего немедленного запуска. Существующие политики
Watchdog сохраняются; отдельный конкурирующий vpn-watchdog не устанавливается.

Исправлена чистая установка WebDAV при umask 077: служебный пользователь теперь
может пройти через родительский каталог хранилища. Данные WebDAV включены в
резервное копирование установщика.

Проверки: 357 тестов основного кода и 99 тестов подписок в Debian 12; затем все
11 тестов snapshot validation, включая две новые проверки восстановления sysctl.
На тестовом Debian 13 выполнены чистая установка и повторный --update, проверены
сохранность конфигураций и БД, ответы TUNA /health 200 и WebDAV PROPFIND 207,
состояния служб и доступность шлюзов Xray. Ошибка первоначального запуска WebDAV
воспроизведена; установщик завершился с ошибкой и восстановил сетевые параметры.
После исправления установка прошла. Недоступные зависимости и источник загрузки
проверены подменой команд в процессе теста: данные и панель остались неизменны.

При аварийном откате процесс панели перезапускался; конфигурация и пользователи
сохранились. Успешная установка и повторное обновление сохранили также PID панели.
Android-клиент, сквозной UDP, нагрузка, облачные каналы OpenFlux и реальная
перезагрузка в этой проверке не проверялись. rp_filter, forwarding, действующие
очереди интерфейсов и глобальные лимиты файлов не меняются.

Версии и SHA-256 бинарных компонентов сохранены. Обновление: «Обслуживание →
Обновить полный выпуск». Откат: «Восстановить резервную копию».
Подробности расчёта и настройки: [адаптивная установка](ADAPTIVE-INSTALL.md).
