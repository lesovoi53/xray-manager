# Установка и восстановление

Используйте полный проверенный выпуск. Инструкции загрузки, обновления и меню: [RELEASES_AND_MENU.md](RELEASES_AND_MENU.md).

## Запуск

На Debian 13 x86_64 с systemd:

```bash
sudo bash install.sh --update
```

Для новой установки с явно выбранным прямым выходом:

```bash
sudo bash install.sh --direct
```

Режим Xray требует существующих совместимых шлюзов ядра; панель необязательна. Сохранённые конфигурации не переводятся на прямой выход автоматически. Поддерживаются Debian 12–13 amd64. Go для установки не нужен.

Новые порты выбираются среди свободных; 443 и 8443 исключены. Сохранённые порты остаются прежними. Если сохранён запрещённый порт, установка останавливается: миграция требует отдельного решения и обновления клиентских адресов.

## Резервирование и откат

Перед заменой файлов выводится каталог `/var/backups/x-manager-XXXXXXXX`. Он содержит секреты и доступен только root. Сохраняются конфигурации, исполняемые файлы, SQLite через backup API, состояния служб и правила iptables. При ошибке выполняется автоматическое восстановление. Установленные системные пакеты и созданные системные пользователи при откате остаются.

Ручной откат из сохранённого полного дистрибутива:

```bash
sudo bash install.sh --rollback /var/backups/x-manager-XXXXXXXX
```

Не запускайте несколько установок/откатов одновременно. При сообщении `ROLLBACK FAILED` не повторяйте установку: сначала проверьте службы и сохранность резервной копии.

## Что проверено локально

В изолированном Debian 13 с настоящим systemd выполнены чистая установка, повторное обновление, сохранение настроек/пользователей/ключей/токенов/портов/кодеков и старой подписки. Проверены отказ зависимости, загрузки, повреждённая конфигурация и отказ настоящей службы с восстановлением. Snell, Mieru, WebDAV и сервер подписок активны без цикла перезапуска; API HTTP 200, WebDAV PROPFIND 207, multi-режим работает от wdavtunnel. Это не доказательство прохождения трафика клиентом через VPS.

Исправлены права каталога WebDAV и безопасная генерация YAML, fallback старого пароля в TUI, распознавание ответа импорта OpenFlux, JSON-конверт Boards с Base64 content, обязательная проверка патча и сборки, установка Mieru без циклических ссылок, обработка ошибок и резервирование.

Тесты групп сравнивают JSON с переданным клиентским fixture, проверяют ограничения, изоляцию пользователей, сохранение URI, HTTP, маскирование токена и TUI create/rename/reorder/disable. Реальный импорт в Android и работа внешних транспортов требуют отдельной проверки.
