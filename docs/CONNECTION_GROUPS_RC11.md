# Серверные группы rc11

В `x-sub` выберите пользователя → редактирование → пункт 12. Установленный редактор также запускается командой `tuna-groups USER_ID`. Он обращается к локальному API сервера подписок; клиент Android не изменяется.

Поддержаны семейства VPN, CSQTT_QWDTT, WEBDAV, OPENFLUX, типы URL_TEST/SPEEDTEST и стратегии BEST/PRIORITY. Категория VPN соответствует семейству VPN; категория BYPASS объединяет остальные три семейства и сама семейством не является. Ссылки участников сохраняются без переписывания неизвестных параметров. Внешняя группа не заменяет внутренний балансировщик OpenFlux. Измерения выполняет клиент, сервер только хранит и выдаёт настройки.

Редактор позволяет создавать, переименовывать, включать/выключать и удалять группы, менять состав, порядок, профиль маршрутизации и параметры тестов. Профили имеют стабильные ID и могут использоваться несколькими группами пользователя. Показ полной ссылки требует явного действия. Удаление группы требует подтверждения.

Старая подписка `/sub/TOKEN` сохраняется. Отдельная секретная ссылка `/sub-json/TOKEN` выдаёт прямой JSON `tuna.subscription`, schemaVersion 1, complete true, capability `connection-groups-v1`. Ссылка доступна в пункте 7 редактора. Токен имеет ту же силу доступа, что и у обычной подписки; не публикуйте его.

GET/PUT `/api/users/USER_ID/connection-groups` доступен только через loopback. Сохранение атомарное; expectedRevision защищает от перезаписи параллельной правки. Изменения хранятся в новой таблице `user_connection_groups`; существующие каталоги не заменяются.

Ограничения: до 2 MiB, 1000 профилей, 100 групп, 2–1000 уникальных участников группы, имя до 200 UTF-16 единиц. Запрещены смешение семейств, неизвестные ссылки на ID, неподдержанные протоколы, неверные диапазоны, URL тестов с реквизитами или fragment. SPEEDTEST использует GET и явно заданный HTTPS URL файла.

Проверки: точное сравнение с переданным `groups-demo.json` (14 профилей, 8 групп), сохранение URI и всех параметров, изоляция пользователей, атомарный отказ неверных изменений, HTTP/маскирование токенов, настоящий TUI через HTTP с созданием, переименованием, перестановкой и выключением группы. Импорт в приложение на телефоне отдельно не проверялся.
