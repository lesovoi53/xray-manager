Кандидат 2026-10-11: проверка обновления, публикации пока нет

Область: Debian 12/13 amd64, серверная часть. Клиент и код панели не изменяются.
Тестовый узел согласован пользователем отдельно. Обновление сохраняет stop/off,
автозапуск, пользователей, ключи, порты и внешние ссылки.

Требование -> реализация -> проверка/ограничение
Mieru, максимальная обфускация -> traffic-pattern сохраняет буквальные / и =,
плюс кодируется %2B -> 12 локальных тестов; импорт реальным клиентом ещё нужен.
Boards -> modify-objects/drop-objects вместо исходящего notify-position;
старый входящий формат сохранён -> TLS/WebSocket тест с настоящим heartbeat.
Mail.ru -> порядок Engine.IO/Socket.IO/auth, активность редактора при разрешённом
редактировании, обработка всех cursor -> локальные handshake/edit/cursor тесты.
Яндекс -> IPv4-first для HTTP/WebSocket/Volga relay, активность OnlyOffice ->
локальные тесты. Ручная SmartCaptcha остаётся ручной; cookies не публикуются.
Cups -> числовые row/column, чанки 4096, раздельная сборка по отправителям,
ограниченные буферы и очистка при reconnect -> локальные тесты перемежения.
Новый wire format Cups требует совместимой стороны клиента; реальная приёмка
не заменяется успешной компиляцией. Ключи, KDF и документные URL не менялись.
Watchdog -> собственные systemd-политики, общий бюджет OpenFlux и recovery timer;
внешний vpn-watchdog не требуется -> тесты отсутствия внешнего владельца.
Новые политики: 5 попыток, 5 секунд; Xray/X-UI 30 секунд; восстановление через
300 секунд после обнаружения исчерпания. Таймер вносит задержку до своего периода.
Пользовательские уже настроенные бюджеты OpenFlux сохраняются при обновлении.
Ручной stop/off не отменяется таймером. Повторное обновление не перезаписывает
настройки нового формата. Старые точно распознанные политики systemd мигрируют.
Восстановление OpenFlux -> одна попытка учитывается один раз в timer и gate;
ошибка start не теряет очередь и не вызывает бесконечный цикл без задержки.
Установщик -> резервная копия включает recovery units; остановленный существующий
timer сохраняется. Сбой возвращает ненулевой код и запускает штатный rollback.
